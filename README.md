# La Scala

Главная страница ресторана La Scala в двух вариантах. Исходник — PSD-макет 2015 года
([прототип в Figma](https://www.figma.com/proto/mAULM5GQgs1Z10nfL2qZhf/LaScala?node-id=0-1)).

| Папка | Что это | Запуск |
|---|---|---|
| [`classic/`](classic) | Адаптивная вёрстка макета «как в 2015»: HTML + CSS + JavaScript + jQuery, без сборки | открыть `classic/index.html` или `npx http-server classic -p 4100` |
| [`redesign/`](redesign) | Современный редизайн на шаблоне `erythroai-droid/templates` (Next.js 15, React 19, GSAP, i18n RU/EN) | `cd redesign && npm install && npm run dev` → http://localhost:3200 |

## classic

- `index.html`, `css/style.css`, `js/main.js`, `js/jquery-3.7.1.min.js`, `img/`
- Сетка макета 1920 / контент 1170px; брейкпоинты 1199, 991, 767, 599px
- jQuery: слайдер в шапке, бесконечная карусель галереи, лайтбокс, мобильное меню, плавный скролл и подсветка пункта меню
- Шрифты Noto Serif / Noto Sans подключаются с Google Fonts

Отступления от Figma-файла:

- В Figma после импорта PSD кегли текста искажены (местами 7–10px), поэтому размеры шрифтов выставлены по PNG-рендеру исходного макета.
- Превью галереи в Figma-файле отсутствуют — в карусели использованы остальные фотографии макета.
- Ссылки «подробнее», «все меню», «все события», «перейти в галерею» и соцсети — заглушки: внутренних страниц в макете нет.

## redesign

- Каждый раздел — на высоту экрана. Тёмные блоки (первый экран, часы работы, галерея) остаются на месте, а следующий блок наезжает на них; футер открывается из-под «Афиши событий».
- В галерее лента фото движется вбок при прокрутке; у галереи, часов работы и футера — затемнённое фото в фоне.
- На экранах до 900px и при «уменьшении движения» — обычная статичная страница без закреплений.
- Тексты: `redesign/i18n/ru.txt`, `en.txt` → `npm run i18n`. Форма бронирования — демо (никуда не отправляет).
